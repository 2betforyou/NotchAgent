# NotchAgent v0.1.1

This maintenance release improves Codex output and scrolling in the notch terminal.

## Changes

- Run Codex in inline mode so Korean text remains legible when scrolling through earlier output.
- Match precise trackpad scrolling to terminal line height instead of jumping a page for a small gesture.
- Clear stale cells when a wide CJK character is overwritten.

## Install

Download `NotchAgent-0.1.1.dmg` if a notarized release is available, or `NotchAgent-0.1.1-macOS.zip` for the local, unnotarized build. Quit NotchAgent first, then replace the app in Applications. Quitting ends open terminal and agent sessions; submitted Codex and Claude conversations can be resumed after reopening.

The unnotarized build may require System Settings → Privacy & Security → Open Anyway on first launch.

## Release checklist (maintainer)

1. Run `bash Scripts/test.sh` and verify the full suite passes.
2. For a notarized DMG and ZIP, configure a Developer ID Application certificate and a `notarytool` keychain profile, then run `DEVELOPER_ID="Developer ID Application: Name (TEAMID)" NOTARY_PROFILE=notchagent bash Scripts/release.sh`. Upload the DMG, ZIP, and `SHA256SUMS` from the output directory printed by the script.
3. Without Developer ID, run `bash Scripts/package.sh` and upload the ZIP and `.sha256` from `Dist/`. Label the GitHub release as an unnotarized build; do not describe it as Apple notarized.
4. Create the GitHub release with tag `v0.1.1` and use this file as the release description. Tag and upload only after checking the built app and files. Do not commit generated binaries.

LaTeX auto-rendering is not part of v0.1.1. Agent CLIs send an interactive terminal screen, so a safe math renderer needs a separate structured output view rather than rewriting terminal cells.
