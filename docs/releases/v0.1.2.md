# NotchAgent v0.1.2 — A clearer workspace, right in the notch

노치에서 프로젝트와 에이전트를 더 편하게 관리할 수 있도록 홈·설정·사용량 표시를 다듬었습니다.

## 새 기능

- **프로젝트 홈**: 세션을 열어도 Home 탭이 왼쪽에 유지됩니다. 시간대에 맞는 문구와 프로젝트별 응답 활동 잔디를 보여 줍니다.
- **과거 활동 가져오기**: 로컬 Claude Code·Codex 대화 기록에서 완료 시각을 읽어 프로젝트 잔디에 반영할 수 있습니다. 잔디는 토큰 수나 열린 세션 수가 아닌 응답 완료 횟수입니다.
- **저장소 정보**: 홈에서 브랜치, 변경 파일 목록, 로컬 디스크 사용량과 GitHub 링크를 확인할 수 있습니다. 선택적으로 GitHub CLI의 기존 로그인으로 현재 브랜치의 PR·리뷰·검사 상태를 조회합니다.
- **임시 채팅**: 중간 화면의 Start here에서 Temp / 임시를 켜면 프로젝트와 분리된 폴더에서 대화를 시작합니다. NotchAgent의 세션 복원·최근 활동 보관·프로젝트 잔디에서 제외합니다.
- **앱 안의 설정**: 별도 창 대신 노치 안에서 설정을 열고 작업 화면으로 돌아올 수 있습니다.

## 사용 경험 개선

- 최소화·중간·최대화 화면의 사용량을 모두 **사용한 비율(0 → 100%)**로 통일했습니다. Claude → Codex 순서이며, 최소화 숫자는 5시간·링은 주간 사용률입니다.
- 사용량을 아이콘·작은 막대·숫자·초기화까지 남은 시간으로 압축했습니다. 갱신 시각은 아이콘을 눌러 확인하고, 오래된 값·오류는 주황색 점으로 구분합니다.
- 직접 그린 에이전트 아이콘을 공식 식별 로고로 교체했습니다. Codex에는 OpenAI Blossom을 사용합니다.
- 중간 화면에서 등록한 프로젝트를 바로 선택할 수 있습니다.
- 이벤트별 노치 알림·macOS 알림·소리를 각각 선택할 수 있습니다.
- 복원 정보가 있는 최근 Codex·Claude 활동은 원래 대화를 새 탭에서 이어 열 수 있습니다.
- 홈의 요소 배치와 여백을 정리하고 잔디 칸을 정사각형으로 맞췄습니다.

## 수정

- 마우스를 움직이기만 해도 Claude 터미널에서 클릭처럼 처리되던 문제를 수정했습니다.
- 실행 환경의 색상 비활성화 옵션이 내부 CLI까지 전달돼 출력이 무채색으로 보이는 문제를 수정했습니다.
- 기본 터미널 배경을 완전한 검정으로 조정했습니다.
- 노치를 접을 때 직전에 사용하던 앱으로 포커스를 돌려주도록 다듬었습니다.
- 작업 화면 하단의 불필요한 상태 줄을 없애고 사용량 주변 여백을 줄였습니다.
- README를 사용자 관점으로 다시 정리했습니다.

## 설치 및 주의 사항

- **Apple Silicon Mac용, macOS 14 이상**입니다.
- `NotchAgent-0.1.2-macOS.zip`을 받아 압축을 풀고 앱을 교체하세요. 기존 앱을 먼저 종료하세요. 종료하면 현재 터미널·에이전트 프로세스와 미제출 입력이 종료될 수 있습니다.
- 이 ZIP은 **로컬 ad-hoc 서명 빌드이며 Apple 공증을 받지 않았습니다.** 최초 실행 시 macOS 개인정보 보호 및 보안 설정에서 실행 승인이 필요할 수 있습니다.
- 임시 채팅은 시크릿 모드나 샌드박스가 아닙니다. CLI 자체 대화 기록·파일 접근 권한은 그대로이며, 생성 파일은 macOS 임시 폴더에 남을 수 있습니다.
- GitHub PR·검사는 설치된 `gh`와 기존 로그인이 필요하며 기본값은 꺼짐입니다. 저장소 변경·push·PR 작성·병합은 하지 않습니다.
- 사용량은 계정 단위의 한도입니다. Claude 값은 NotchAgent에서 연 Claude 세션의 응답 이후 갱신되며, 새로고침은 마지막 값을 다시 읽습니다.
- 자동 업데이트, Siri AI 연동, LaTeX 자동 렌더링은 이번 버전에 포함하지 않습니다.
